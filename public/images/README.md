# Product Images

Letakkan file gambar produk di folder `app/assets/images/` dengan nama-nama berikut sesuai dengan kebutuhan homepage dan halaman lainnya.

## Homepage Images

### Hero Section

- `hero-bag-showcase.jpg` - Gambar hero banner (1600x900 ideal, minimum 1200x800)

### Category Showcase

- `handbags-hero.jpg` - Tas tangan hero (900x1200, vertical)
- `backpacks-card.jpg` - Ransel card (900x700, landscape)
- `accessories-card.jpg` - Aksesori card (900x700, landscape)

### New Arrivals

- `new-arrival-1.jpg` - Tas Selempang Luxe (420x520, portrait)
- `new-arrival-2.jpg` - Tote Kerja Aura (420x520, portrait)
- `new-arrival-3.jpg` - Clutch Noir (420x520, portrait)
- `new-arrival-4.jpg` - Sling Mini (420x520, portrait)

## Format Requirements

- Format: JPG, PNG, atau WebP
- Quality: High resolution, optimized untuk web
- Color Space: sRGB
- Orientation: Sesuai dengan dimensi yang diminta

## Path Location

Folder untuk semua gambar:

```
app/assets/images/
```

## Notes

- Gambar di-import secara static di page.tsx
- Semua gambar sebaiknya dioptimasi untuk performa web
- Gunakan format WebP untuk file lebih kecil (jika didukung browser)
- Pastikan gambar memiliki aspect ratio yang benar sesuai ukuran
